# User Flows

## Fill and sign

1. User opens the site.
2. User selects a local PDF.
3. The PDF is rendered locally.
4. User fills existing fields or places text.
5. User adds a signature and date.
6. User reviews the pages.
7. User downloads the completed PDF.
8. User closes the document or tab.
9. Session data is discarded.

## Correct visible text

1. User opens a PDF.
2. User selects Whiteout.
3. User covers incorrect visible content.
4. User adds replacement text.
5. Application labels this as a visual correction, not secure redaction.
6. User downloads the PDF.

## Organize pages

1. User opens a multi-page PDF.
2. User enters page-management mode.
3. User rotates, reorders, duplicates, inserts, or deletes pages.
4. User downloads the resulting PDF.

## Unsaved exit

1. User modifies a document.
2. User attempts to refresh, close, or open another document.
3. Application warns that changes have not been downloaded.
4. User either remains or discards the session.
