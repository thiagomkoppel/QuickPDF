# PROJECT_PHILOSOPHY.md

QuickPDF exists to solve one problem:

"I received a PDF and need to make a few edits before sending it back."

Examples:

- Fill a form
- Add text
- Add a signature
- White out incorrect information
- Replace visible text
- Add a checkmark
- Add an image

The application is intentionally NOT:

- Adobe Acrobat
- Microsoft Word
- Photoshop
- A document management system
- Cloud storage
- An office suite
- A collaboration platform

Core principles:

- Extremely fast
- Extremely simple
- Browser only
- No login
- No backend
- No database
- No cloud
- No persistence
- Privacy first
- Open → Edit → Download → Done

Every new feature must justify its existence against these principles.

If a feature does not make the common "I need to edit this PDF quickly" workflow better, it should not be implemented.
