# Accessibility

## Target

Meet WCAG 2.2 AA for the application interface wherever technically applicable.

## Requirements

- Keyboard access to every tool and command.
- Logical focus order.
- Visible focus indicators.
- Accessible names for icon buttons.
- Dialog focus trapping and restoration.
- Screen-reader announcements for page changes, element additions, deletions, undo, redo, errors, and export completion.
- Non-color indicators for selection and status.
- Sufficient text and control contrast.
- Large touch targets.
- Reduced-motion support.

## Canvas accessibility

The visual canvas must be paired with an accessible structure describing:

- current page;
- placed elements;
- selected element;
- available actions;
- form fields.
