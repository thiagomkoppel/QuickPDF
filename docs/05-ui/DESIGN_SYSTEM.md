# DESIGN_SYSTEM.md

## Purpose

This document defines the visual language of QuickPDF.

QuickPDF is not a productivity suite or office application.

It is a lightweight browser utility.

Every screen must feel:

- clean
- calm
- focused
- fast
- modern

The PDF itself is the primary visual element.

The interface exists only to support editing.

---

# Design Philosophy

The application should feel like a native desktop utility rather than a business dashboard.

Visual inspiration:

- Apple
- Linear

Avoid styles inspired by:

- Microsoft Office
- Adobe Acrobat
- Jira
- Salesforce
- CRM systems

---

# Core Principles

The interface should be:

- minimal
- spacious
- distraction free
- predictable
- responsive

Every feature should require as little explanation as possible.

# Border Radius

Buttons

12px

Cards

16px

Dialogs

18px

---

# Shadows

Very subtle.

Never heavy.

Prefer soft elevation.

---

# Icons

Use Lucide.

Icons should remain monochrome unless representing status.

---

# Buttons

Primary

Filled purple

Secondary

White

Border

Danger

Red

Do not use more than one primary action per screen.

---

# Animations

Duration

150–200 ms

Ease

ease-out

Avoid:

- bouncing
- scaling
- flashy transitions

Animations should feel invisible.

---

# Empty States

Every empty state should help the user continue.

Never display blank screens.

---

# PDF Priority

The PDF should occupy approximately 70–75% of the available width on desktop.

The interface must never visually overpower the document.
