# LANDING_PAGE.md

## Purpose

The landing page has one goal:

Open a PDF.

Nothing else.

---

# User Journey

User arrives.

↓

Drops PDF.

↓

Editor opens.

The ideal interaction takes less than ten seconds.

- highly visible
- works immediately
- accepts click and drop
