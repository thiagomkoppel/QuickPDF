# USER_EXPERIENCE.md

## Product Philosophy

QuickPDF solves one problem.

"I need to edit this PDF quickly."

Nothing else.

---

# Primary Workflow

Open

↓

Edit

↓

Download

↓

Done

---

# Maximum Complexity

The common workflow should require no more than five clicks.

---

# Every Feature Must Answer

Does this make:

Open → Edit → Download

faster?

If not, it probably should not exist.

---

# Editing Philosophy

Users edit visually.

They are not editing the original PDF structure.

The application places editable overlay elements.

Only export writes them into the PDF.

---

# Performance

The application should feel immediate.

Long operations should always display progress.

---

# User Trust

Always explain:

Nothing leaves your browser.

No account required.

Documents disappear after the session ends.

---

# Simplicity

The application should always choose:

simple

over

powerful.

Avoid advanced options until there is clear user value.
