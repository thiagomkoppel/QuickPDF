# User Warnings

## Whiteout warning

Whiteout is a visual cover only. The UI must say:

> Whiteout only covers content visually. It does not securely remove underlying PDF data.

Do not call whiteout redaction or imply secure deletion of underlying PDF data.

## Export status

Show export progress while the edited PDF is being generated. On success, tell the user the download filename and keep the editor open. On failure, show an error without discarding edits.
