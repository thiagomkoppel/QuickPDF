# MVP Implementation Plan

## Increment 1 — Foundation

- Complete Phase 0.
- Establish CI and quality gates.

## Increment 2 — Essential completion tools

- Text.
- Date.
- Checkmark and cross.
- Signatures.
- Initials.
- Images.
- Whiteout.
- Element properties.

## Increment 3 — Forms

- Detect AcroForm fields.
- Text fields.
- Checkboxes.
- Radio buttons.
- Dropdowns.
- Export field values.

## Increment 4 — Page management

- Thumbnails.
- Rotate.
- Reorder.
- Duplicate.
- Delete.
- Insert from another PDF.
- Export selected pages.

## Increment 5 — Responsive and accessible editor

- Desktop refinement.
- Tablet layout.
- Mobile toolbar and sheets.
- Keyboard workflows.
- Screen-reader structure.

## Increment 6 — Reliability

- Large file behavior.
- Unsupported PDF handling.
- Export compatibility.
- Performance profiling.
- Privacy and security verification.

Every increment follows TDD and must leave the product releasable.
