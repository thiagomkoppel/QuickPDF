# Accessibility Completion Roadmap

## Goal

Complete accessibility verification after UI and PWA delivery.

## Scope

### Keyboard

- Toolbar navigation
- Inspector tabs
- Layer selection and reorder
- Dialog focus trapping
- Escape behavior
- Delete/Backspace safety
- Shortcut documentation

### Screen readers

- Correct landmarks
- Accessible icon-button names
- Selected tool state
- Page and zoom announcements
- Inspector state
- Layer visibility and lock state
- Progress announcements

### Visual and touch

- Contrast
- Visible focus
- Reduced motion
- Text scaling
- High zoom
- Minimum touch targets
- No hover-only actions

## Acceptance criteria

- Automated checks pass.
- Keyboard-only core workflow succeeds.
- Screen-reader smoke test succeeds.
- Phone Quick Edit remains understandable.
