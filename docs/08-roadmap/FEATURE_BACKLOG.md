- Progressive Web App

- Performance optimization
- Accessibility completion
- Browser compatibility
- Localization

- Highlight
- Shapes
- Sticky notes
- Comments
- Stamps
- Additional curated fonts
- Page rotation
- Page duplication

- Page extraction
- Merge and split
- Compression

## Forms

- Checkbox and radio controls
- Field detection
- Optional local autofill

## Document intelligence

- Search
- OCR
- Text extraction
- Suggested field placement

## Project and recovery

- `.qpp` project files
- Optional session recovery
- Optional local autosave
- Project encryption

## Explicitly out of current scope

- Cloud document storage
- Real-time collaboration
- Server-side PDF processing
- Advertising
- Behavioral analytics
- Secure redaction claims
