# Localization Roadmap

## Initial languages

1. English
2. Portuguese
3. Spanish

## Scope

Localize:

- landing page
- mobile Quick Edit
- desktop editor labels
- inspector labels
- dialogs
- errors and warnings
- loading stages
- install guidance
- privacy navigation
- accessibility labels

## Architecture

- Centralize user-facing strings.
- Do not localize serialized project keys.
- Preserve user-entered PDF content exactly.
- Support longer translated labels without clipping.

## Deferred

- Community translations
- Right-to-left layout
